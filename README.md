# 🍋 Control de Stock - Mayorista LIMON

Sistema integrado y web-app para la gestión, control de inventario y registro de movimientos de stock para **Autoservicio Mayorista LIMON**.

---

## 🚀 Características Principales

* **Panel de Control en Tiempo Real:** Métricas automáticas de total de bultos, valoración total en ARS y control de vencimientos.
* **Bot de Comandos Simulado (WhatsApp):** Interfaz para actualización rápida de stock desde el celular mediante comandos (`SUMAR`, `RESTAR`, `STOCK`).
* **Sincronización & Respaldo:** Guardado en memoria local y exportación completa a formato CSV / Excel.
* **Instalable como PWA/Web App:** Diseñado para usarse desde computadoras y dispositivos móviles.

---

## 📱 Comandos del Bot para Celular

* `STOCK [producto]` - Consulta las cantidades disponibles de un producto.
* `SUMAR [id] [cantidad]` - Registra el ingreso de bultos al inventario.
* `RESTAR [id] [cantidad]` - Registra la salida o venta de bultos del inventario.
